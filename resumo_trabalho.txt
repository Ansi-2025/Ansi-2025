Resumo do que foi feito e próximos passos

1. Contexto geral
- Projeto: Cancao de Fe, app React/Vite com backend Supabase e integração Shopify.
- Objetivo atual: implementar fluxo de checkout Shopify, webhook de pagamento e melhorar UX do formulário de pedido.

2. O que fizemos
- Implementamos o backend de checkout Shopify.
  - Adicionada integração em `src/integrations/shopify/client.ts`.
  - Criado serviço em `src/lib/shopify.service.ts` para gerar checkout.
  - Foi usada a variável `SHOPIFY_ACCESS_TOKEN` e `SHOPIFY_STORE_DOMAIN` no ambiente.
- Desenvolvemos a validação e processamento do webhook `orders/paid`.
  - Implementado em `src/lib/shopify.webhook.ts`.
  - Validamos HMAC e atualizamos o pedido no Supabase usando `shopify_checkout_id`.
- Ajustamos a lógica do pedido no backend.
  - Em `src/lib/order.functions.ts`, definimos duração fixa do preview (`duracao_segundos: 45`).
  - Removemos a opção de duração customizada pelo cliente.
- Melhoramos a interface do pedido.
  - Em `src/routes/index.tsx`, adicionamos botões de sugestão que preenchem automaticamente a descrição.
- Executamos build local e deploy no Vercel.
  - `npm run build` passou.
  - Deploy realizado com `npx vercel deploy --prod`.
- Commit e push feitos.
  - Commit principal: `Add description suggestion buttons for order form`.
